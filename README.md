# AGV Graduation Project · Part 1: Mechanical & Cross-functional Prep

Mechanical design, manufacturing and the mechanical preparation for the electrical and software teams (CAD, URDF, mounting points). Part 1 deadline: **Nov 15, 2026**. Electrical (Part 2) and Software (Part 3) will be added later.

📋 **Task board (deadlines, who works on what, timeline):** https://salehnassar.github.io/agv-task-portal/

## Rules

- **Phases run in order: A → B → C → D.** A phase starts only when the previous phase is 100% complete. Tasks inside a phase run in parallel.
- **Phase D starts after the mechanical work**; its tasks will be added later.
- **Document the same day.** Open your task on the portal → **Upload to my task folder** → commit. Update the task README (pencil icon).
- **Commit messages:** `Task N: what you did`. When a task is finished, include **`Closes Task N`** and the board moves it to Done automatically.
- Web upload max 25 MB per file; bigger CAD → GitHub Desktop (max 100 MB) or a STEP export.
